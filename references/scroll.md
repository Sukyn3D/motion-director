# 滚动进入、退出与重新进入

正常模式默认对范围内合格内容组/控件提供进入、退出和重入。不是首次observe后unobserve即结束。用户允许one-shot的特定叙事节点才可具名改用一次性；该例外不能自动传播全站。

## 正常模式的可感知逐步入场

对下方尚未出现的标题/正文有界组、图片、卡片与UI，在JS增强已接线后落实 `opacity:0 + translateY(向下偏移)` → `opacity:1 + translateY(0)` 的非线性渐入上移。默认完整透明度行程；位移与时长按内容尺度、品牌和阅读选择，16–32px / 280–450ms可作起点，不是全站固定值，也不应自动缩为看不出的1px/极短闪变。页面初始已可见、锚点/历史恢复时已在阅读的内容直接按当前可见状态初始化，不倒退到隐藏。

默认新内容入口可用可见事件触发的可打断时间过渡，保证在真实视口中能看到中间过程；选择滚动进度驱动时需核对可见带长度，快速滚轮跨过阈值也不能使所有动作在进入前就结束。淡入与空间分轨、父组错峰与累计延迟有界。不同家族的显露造型可不同，基础透明度/位移入口不能遗漏；长段落/高列表拆成可读有界组，不能把整页长容器作为一个隐藏对象。

## 状态和坐标

为稳定对象/组定义 outside-before / entering / visible / exiting / outside-after，用同一可见进度驱动当前呈现。入口、出口依赖真实视口边缘与滚动方向；先定义可读中央区域，再在边缘带做低幅度转换。方向快速反转，目标进度可立即改向，当前位置/速度不清零。

可选实现：支持的原生view/scroll timeline+能力fallback；IntersectionObserver加当前呈现控制器；系统平台可见状态/滚动位置。位置→进度映射可用smoothstep等非线性映射，原生滚动本身不劫持、不因动画追加跟滚延迟。observer只给事件，不证明中途轨迹；合同需采样实际样式或几何。

## 必须保护

- 默认HTML/CSS内容可见，JS初始化之后渐进增强；无JS/不支持API不能留下整页隐藏。
- 向上、向下、跳转、浏览器恢复、resize和快速来回均保持稳定身份。退出不等于业务删除，aria/焦点不随opacity装饰变化变成失效。
- 保护视口内有焦点/正在输入、按住或拖动的目标，抑制隐藏/退场位移并保持可读；离屏遗留焦点不应冻结整组滚动呈现，不主动blur或抢焦点。按实际可见性与操作状态恢复进退。滚动exit不能把目标移走逃开指针。
- 虚拟列表以业务ID为身份，复用节点时重绑定呈现状态，不能将上一行的隐藏/动量继承到另一对象。
- 父组scroll和子控件hover/press用独立图层，避免同一transform双所有者。大批对象限制可见组及调度工作量，稳定时停止rAF。
- 减少动效：进退保持可见静态内容，停止非必要空间/透明度隐藏；必要阅读进度仍真实。运行中切换立即收敛。

验收：完整下滚与上滚、退场中反转、数次重入、焦点留在组内滚动、触屏、初始/动态减少动效、无JS内容。不能以“滚动时某个元素淡入过”证明进退已覆盖。

## 首次出现与双向滚动分开落地

首次进入页面/路由/打开/插入：首屏标题、正文组、图片与UI要有可辨识的组出现（如低幅上移与渐入），不是等首屏早已显示后设置最终样式。滚动：上下两个边缘的进入、退出、重入分别设计；中央阅读区域保持稳定，不在视口中央淡掉整段文章。不机械逐字编舞，也不让高个内容组的整个body因边缘运动失去可读性。

绑定前确认window或实际嵌套滚动容器、可见带/阈值、测量外层和动画内层；适配初始路由位置、恢复、resize、懒加载与动态插入。启动检查实际匹配数量、运行偏好及每个代表组；不能悄悄因reduce覆盖、错误root、one-shot/unobserve或fallback使正常模式静止。共享控制器可覆盖多实例，仍须记录文字、图片和UI各自归属。

验收需从正常模式的起始状态实际向下滚动到中部/底部，再向上返回，采样真实标题/正文组/UI呈现层在上/下边缘的位移与透明度；至少一次退场中反向、多次重入，以及首屏出现。只采样装饰kicker、只检查observer/类名、只有scrollbar在动或只检查最终opacity=1不能通过。正常速度、真实滚轮/触屏确认实际文字和UI动作可辨；测量动作区间是否早于内容出现而结束，或因旧焦点永久被保护。可见带按视口、组大小和阅读空间选择，过弱时按合同调整，不能声称“高级到看不见”。正常模式未见从透明/偏移到可读端点的真实入场，需排查选择器、root、阈值、启动/挂载时机、CSS覆盖、one-shot配置、视口恢复与误启用reduce；不能用最终opacity=1或读过reveal文档结案。无运行环境/案例源码时只报告规则检查与未测，不声称用户案例已修复。

## 退出必须在可见边缘内得到证据

exit 不是元素完全离屏以后才设 opacity=0。按内容高度与真实 scroll root 设计上下边缘可见带，使正常滚轮/触屏速度下离开过程能被观察；中央阅读区和仍在操作的内容保持清楚。固定极窄阈值、基于已变换自身 bbox 产生反馈环、或只在离屏后才播放退出，不能用“有 exit 代码”通过。测量稳定外层、动画内层；长内容拆成可读组，避免为看见退出而提前隐藏正在阅读的正文。

对同一稳定对象逐项记录下边缘进入、上边缘退出、上边缘重新进入、下边缘退出；上下双向的中间 opacity/位移或所选等价机制需有实际可见帧。覆盖 window 与实际嵌套滚动容器、初始恢复、快速滚轮、慢速和中途反向，核对真实标题/正文、图片和 UI 家族。单次入场样本不能替代退出，离屏数值变化不能替代可见退出；具体路径未测就记 unknown，不沿用入场通过结论。
