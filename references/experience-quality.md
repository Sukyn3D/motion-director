# 表现价值与控件造型

## 补全、细化与保留

功能解释、品牌性格、氛围、视觉精致度与愉悦感均是有效价值。范围内没有动效的合格节点补齐；已有动效也从接触感、显露方式、时间关系、状态接续与整体气质检查提升空间，不能只因已经动起来就跳过。

针对每个家族提出贴合结构的深化方向，选正常速度下更细腻、有辨识度的方案。例如变化来源、材质与边缘、显现遮罩、颜色层次、接触与恢复的关系，而非轮流套fade/scale或增加数量。极简、高频场景也有自己的表达；评估后确实成熟的表现可以keep，记录优势及不改的理由。比较保持内容、布局端点、业务及技术栈一致。

已有润色在无具体冲突时保留或打磨，不必伪造功能理由。删除/减弱须有证据：误导语义、遮挡阅读、破坏主次/品牌、影响命中或焦点、实测性能问题、明确偏好冲突。优先调整幅度、密度、频率、时序、触发范围、分层或替代机制，延续仍有价值的气质；不能只写“无功能”“多余”“不够克制”。纯装饰指针响应不自动等于假按钮。

持续背景、尾迹、粒子、呼吸按场景评估，有价值时可保留并提供适用的暂停/停止及减少动效。报告分开说明覆盖补全、行为修复、体验细化和保留理由，不能以动画数量证明品质。

正常模式已有主反馈的感知强度默认保留；有界缩放允许清楚的放大，并不意味着统一压到近乎不可见。优化需比较改前/改后同样输入的实际表现，具体非降级方法见 [enhancement.md](enhancement.md)。

## Icon保持位置与方向

Icon自身及组成线段不做独立平移或旋转动画，包括hover/focus/press及状态过渡；不通过移动/旋转子路径绕过规则。使用有界且不扭曲含义的缩放、颜色/描边/填充、描边显现、兼容形状变化或在同一位置对齐的交叉淡变。菜单/关闭、展开/收起、播放/暂停也用对齐的形状交接，业务值与aria立即正确，反向从当前呈现接续。不兼容SVG不声称通用morph。

固定的布局居中或静态朝向不属于动画。Icon随真实容器入场、共享窗口交接或开关thumb移动属于容器关系，不增加Icon自己的漂移/旋转轨道。旋转材质/图像的其他空间机制不受Icon规则替代；加载反馈可用描边/透明度循环，不以旋转Icon实现。

审查稳定和中途姿态，不能让加号像关闭、播放像方向箭头、探索提前像暂停/完成。状态变化要由真实selected/expanded/loading等驱动；缩放和morph也不能制造假状态。

## hover、focus、press分别设计

hover表示探索，focus表示当前位置，press表示接触，不能混为selected或结果。依据既有表面、留白、密度、邻接、品牌与对比选择反馈，不统一加底色。

| 空间/组件 | 可选方向 | 避免 |
|---|---|---|
| 透明Icon、正文链接、窄导航 | 颜色/描边/填充、有界缩放、下划线；focus清楚的线条/轮廓 | 无意新增底板，挤压邻接，局部Icon漂移或旋转 |
| 实体按钮 | 合适颜色/亮度、显露方式、光影与接触层，内部图形协作 | 命中区漂移，所有按钮照抄同一组合 |
| 作品卡片与品牌动作 | 图像探索、边缘/光影、表面与子层的相关节奏 | 伪造可点击性，拉伸或遮挡正文 |
| 密集工具与高频列表 | 短、小而清楚的复合反馈与恢复 | 统一抬升/铺底，长恢复队列 |

候选机制按结构选择，不为凑第二轨道加底色或粒子。极简控件也可通过接触→状态→恢复、局部图形显现表达层次。键盘焦点不能只靠微弱缩放；触屏用press/状态替代hover。leave、blur、cancel及动态偏好切换恢复可靠姿态。

验收真实hover/focus/press与快速改向，观察内部Icon局部矩阵、形状、填充、目标和表面；区分容器空间变化与Icon独立变化。数值可验证机制，正常速度视觉评审才能判断精致度与辨识。

## 反馈贴合可见造型，内容层不受误裁切

按可见造型与操作含义选反馈，不把控件的 DOM 矩形当作装饰轮廓。矩形实体按钮可用贴合自身圆角的表面/边缘；圆形按钮用圆形表面、环或中心图形；透明心形等 Icon 用图形自身的缩放、描边、填充和对齐状态交接；滑块用 thumb、已填充轨道的颜色/厚度或接触材质。禁止用一条通配的按压 box-shadow/outline 给这些对象统一套矩形框。真正矩形控件使用矩形反馈可以成立，依据是可见造型，而非实现省事。

键盘 focus-visible 是定位与可访问性反馈，不等于点击按压。保持清楚、足够对比的焦点指示，可沿轮廓/圆角，或在图形变化之外加易辨认的专用标记。不能为去掉生硬按压框而全局 outline:none；平台原生焦点、强制颜色模式有可靠保底。指针恢复焦点不自动获得一整套 hover 表演。

滑块分别设计 track/thumb 的 hover、press/drag、release/cancel 与键盘调整，真值与填充进度忠实跟手；hover 可增大 thumb/加强填充轨道，按住时可加接触形变。整个合法命中范围都应有相应探索反馈，包括轨道和 thumb，不能只有拖动时才动；数值、标签、整组矩形不代替滑动部件反馈。

把图像的 zoom/crop/mask 放在媒体呈现层，蒙版/overflow 只裁预期图像或装饰层。文字、标签、按钮、焦点环有独立可读层；不让图片 hover 同时改变它们的 clip-path/透明度而损失可读性。明确允许的文字显露机制也须保留正常状态和操作中的全部必要信息，不通过持续裁掉文字表现材质。测试长文案、不同素材比例、字体就绪、窄屏和运动峰值；审查每个裁切祖先及实际遮挡，不能只查 img 的 scale。

同一控件组中，同造型、同意图的图片/卡片采用统一主 hover 机制和退出恢复；图片标签、文件格式、加载方式不构成随意换机制的理由。参数可按尺寸和构图归一化。合理变体以结构、造型、材质或语义划分并具名记录，圆按钮与长胶囊按钮不因都叫 button 就被强制同方案，也不为追求花样让相同图库卡片各动各的。装饰/图片/真实按钮分层后，所有实例仍需检查实际响应。
