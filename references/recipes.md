# 产品交互动效配方

本表继承上传的Motion Orchestrator作为语义与异常处理原料，并非完整控件成品。先按[coverage.md](coverage.md)覆盖全部合格控件，再按[composition.md](composition.md)组合主次响应；表中的单项press、颜色或淡入不能替代完整出现、hover/focus、press/cancel、状态及滚动生命周期。所有自主空间过渡非线性，反向从当前呈现接续。表现与验收最终遵循本版规则。

参数起点见 [tokens-physics.md](tokens-physics.md)；平台机制见 [platforms.md](platforms.md)。每条写明目的、变化、异常和验收，不要求所有配方用于同一产品。

| 配方 | 目的与动作 | 中断/异常 | 减少动效 | 验收重点 |
|---|---|---|---|---|
| 按钮 press | 接触反馈；装饰层 scale 1→0.98→1，效果 100ms；点击区域固定 | pointercancel、失焦恢复；业务 loading 单独处理 | 颜色/边框即时反馈 | 键盘、触摸结果一致；连续按不堆队列 |
| Toggle | 明确二态；业务值即时改变，thumb 空间快速过渡，颜色单调 | 反向从当前值继续；失败回到真实状态并说明 | 即时终态 | 快速切换终态等于最新输入；正确 aria-checked |
| Tab 指示条 | 标示当前目的地；指示条从当前几何位置移向选中项 | 大跨度不穿过无关内容；resize 重测 | 即时位置与选中状态 | 快速 A→B→C 无闪回 B；键盘导航有效 |
| Accordion | 展示内容所属关系；框架 layout/受测尺寸动画，图标辅助 | 反向展开，内容高度变化重新布局 | 即时布局 | 不拉伸正文；焦点不落入已隐藏内容 |
| Popover / 菜单 | 从触发点出现；小位移与独立透明度 | Escape、外部点击、重新打开；只对模态锁焦点 | 即时显示或短淡变 | 位置避开视口边缘；返回触发焦点 |
| Dialog / Sheet | 表明当前任务层；sheet 从真实边缘进入，蒙层单调 | 支持系统返回、取消和手势中断；处理请求中的关闭语义 | 静态打开、正常焦点 | 模态背景不可误操作；关闭焦点恢复 |
| 卡片→详情 | 核对对象与实际图像：默认普通弹出；相同封面仅具共享资格，按偏好/明确设计决策采用；内容独立入场 | 中途返回从呈现状态交接；不能串错对象 ID | 直接进入详情 | 中途无突跳、图片不变形、标题可读 |
| 顶级导航 | 说明目的地变化；一般轻淡变，层级变化才用方向 | 快速返回、历史记录、深链 | 直接切换 | 不制造不存在的父子关系；平台返回手势保留 |
| 列表插入/删除 | 保持空间记忆；FLIP/平台 item 动画，其余项让位 | 并发修改、重排、撤销由稳定 ID 对齐 | 直接重排 | 删除错位、索引 key、滚动锚点漂移都需检查 |
| 拖拽排序 | 对象跟手，插槽预览，松手按合理速度稳定 | pointercancel、滚动边缘、越界与 Escape 还原 | 保留直接操控；提供上下移动按钮 | 不靠弹性追手；键盘可完成同一任务 |
| Swipe action | 揭示行操作、达到阈值再提交，边界轻阻力 | 取消/反向/屏幕阅读器均有操作按钮 | 保留必要直接操作，移除装饰回弹 | 阈值可理解、破坏性动作可按业务需求撤销 |
| Loading→结果 | 告知等待与真实完成；内容可读，spinner 不冒充进度 | 失败与超时有文案和重试；离开页面停止 | 静态“加载中”、真实进度、结果即时 | 不因动画结束伪造成功；状态播报不过量 |
| Toast / Undo | 告知改变，轻入场、不抢当前焦点 | 重复信息合并；重要信息不能随短计时丢失 | 即时显示 | Undo 可键盘访问；计时与阅读/焦点策略匹配 |
| 收藏 / 成就 | 低频情绪；图标局部有界缩放/填充，相关容器交接到真实目的地；Icon不独立位移/旋转 | 下一次输入立即响应；不存在目标则不用飞行 | 静态选中与文本确认 | 次要动作不挡操作；真实计数不回弹失真 |
| Scroll progress / reveal | 解释阅读位置或信息层级；原生滚动、渐进增强；组进入、退出、重入都有可逆呈现 | 退场途中反向延续；focus/held保持可见；默认内容可见 | 静态内容，必要进度仍可读 | 下滚/上滚/快速反向/重入实测；无JS不空白；不劫持滚轮；见[scroll.md](scroll.md) |

## 编排约束

一组对象首先按信息关联分组，然后选择同步或少量 stagger。总延迟上限由任务决定；默认累计 120ms 起点，长列表仅对首屏少量项目编排。原始阅读顺序与无障碍树不为视觉 stagger 改写。

品牌瞬间可以用“准备→主动作→稳定”的节拍，高频操作直接“反馈→状态”。次要动作振幅、对比与持续时间低于主动作。一次错误提示需明确文字；不默认摇晃整个表单。

避免把统一 hover 抬升或全页 fade-up当作完成设计。鼠标尾迹、装饰粒子、呼吸/背景变化等可表达美感与品牌，先评估价值、密度、触发、性能与可结束/可关闭性；不得只因无功能删除。相同语义可保持相同动作，不能为“去 AI 味”而随机化每个按钮。用户明确要求的配色、布局与系统字体均可保留，审美判断不能成为普遍禁令。

Hover/focus造型先读[experience-quality.md](experience-quality.md)：颜色、局部缩放、线条、空间与底色按场景选；Icon本身不独立位移或旋转，状态形状采用兼容morph或对齐淡变。Popover/Dialog/卡片详情以及缩略图→视频播放器按[overlays.md](overlays.md)补齐来源、反向关闭、内部内容与媒体生命周期；相同业务对象不自动表示同一视觉素材；不同封面用完整普通弹窗，普通窗口为默认；实际同图且符合共享身份只是资格，按用户偏好与明确采用理由决定是否进入共享图像交接。尺寸变化、卡片选型与滚动reveal分别按相关参考接线，不能用单模式代替。
