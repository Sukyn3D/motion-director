# 统一运动语言与节奏

设计统一读[design-foundations.md](design-foundations.md)：Apple、Material、Disney、Fluent与Carbon并列组织运动语言，分别检查连续跟手、分轨、主次表现、层级编排与语义效率。三种用途模式不替代任一视角，也不与Material官方scheme同义。

本版结合上传包的 productive / expressive / narrative 和动画原则迁移；见[principles.md](principles.md)。三种模式都完整覆盖微交互，区别是幅度、恢复、材料和叙事关系，不是一个有动画另一个不动。

productive：高频、密集任务用短恢复、固定目标、局部复合反馈；expressive：重要结果/品牌动作更有物理与材料表现，幅度按既有风格和可感知目标决定，合适时轻弹；narrative：浏览/作品/故事强调组、空间和阅读节拍。可为关键家族设置受控变体，相同语义保持一致。

主响应解释对象/选择/层级/材料；相关次响应解释接触、icon/子元素与稳定；点缀可有功能/品牌/美感/氛围价值，保持主次；持续自主运动有适用的暂停/停止与减少动效策略。丰富度按结构与主次评审，不按特效数评分。同组入场可错峰，累计延迟有预算（上传包起点24ms间隔、120ms上限），控件无需等队列就能操作；滚动进退从当前值接续。

自定起点：反馈100–180ms、状态180–280ms、内容进退280–450ms、复杂交接350–600ms，按尺寸/距离/频率调整；与[tokens-physics.md](tokens-physics.md)的productive/expressive/narrative起点兼容，不能混称公司官方token。进入加速并稳定，退出更利落；状态效果单调非线性，空间可用连续弹簧；直接输入和真实进度不追加装饰滞后。

幅度、显露行程、对比与时长一起校准感知，不全站默认最小参数。既有有效反馈正常模式不因“统一语言”变弱，同设备同输入检查回归；轻弹描述过冲与恢复，不是把主响应都削弱。

位置/速度/身份/状态连续先落实，再调整节奏和品牌。运动结束到稳定姿态不等于“这个控件不需要动效”；下次出现或事件有完整响应。来源及迁移边界见[sources.md](sources.md)。
