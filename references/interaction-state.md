# 输入状态、组合反馈与覆盖层返回

适用于任何组合 hover/focus/press、指针捕获、菜单/弹窗往返或页面暂停恢复。重点是不同轨道共享真实输入合同，而不是共享一种造型。

## 一个可校准状态模型

落实时以 [lifecycle-regressions.md](lifecycle-regressions.md#1-焦点来源与探索状态) 的 focus 来源与 pointerleave 回归为准；不得将普通 focus 当探索持续条件，也不以强制 blur 移除键盘焦点解决。可复用输入状态原料位于 `../assets/runtime/input-state.mjs`。

分别保存 pointerInside（精确指针）、focusVisible（键盘定位）、pressed（有效接触/键盘激活）、selected/expanded 等业务状态，以及 suspended/disabled。普通 focus 和 hover 不是同一个布尔值；programmatic focus 返回与触屏点击也不能自动当 hover。业务状态立即更新；外观由同一状态快照派生，各属性仍保留自己的运动 owner。

颜色、填充、扫光、边缘、图形等相关轨道在同一次输入事务中重定向到一致目标。不能一部分由 CSS :hover、一部分由 JS hovered||focused 驱动而互不协调；混用时须明确状态来源、优先级及恢复校准，证明两者不分叉。光效的 active/phase、播放句柄和完成回调也属于状态合同；离开、取消和覆盖层返回时确定继续、回收或重新触发的策略，从当前呈现交接。不能仅重置底色，留下半截扫光暂停在表面；空白处再次点击才恢复属于失败。

## 命中与事件边界

稳定语义控件承接输入，内部视觉层负责运动。整个合法命中区，包括 SVG、文字、中心 icon、内边距和边缘，均可触发相同探索/激活合同；不得只给背景层绑定。纯视觉伪元素、光效、快照不截获事件（Web 可用 pointer-events:none），但不能把真正的嵌套操作误禁用。enter/leave 依据整个控件边界，不能把子元素之间的 pointerover/out 当成离开。检查 elementFromPoint/实际事件路径、top layer 与叠层；中心 icon 无响应时先定位实际命中，不能仅补 transition 猜测修复。

press 记录实际 pointerId/激活键；pointerup（包括控件外）、pointercancel、lostpointercapture、键释放、blur、window blur、隐藏/卸载、禁用、弹窗打开与减少动效改变均有对应清理。CSS 属性归零不能代替清除控制器里的 pressed/hover 缓存，否则下一次 update 会把旧状态写回。键盘行为沿平台语义，不把所有键当激活。

## 覆盖层进入与返回是一组事务

1. 打开覆盖层时立即清除无效按压/捕获，暂停被遮挡触发器的探索轨道，并明确扫光等阶段的退出；不依赖 pointerleave 必然发生。保留业务状态，不克隆/重绑定真实触发器。
2. 关闭时取消旧回调、清理临时层、恢复背景与焦点，然后在实际可命中状态重判精确指针所在处和当前键盘焦点。Web 可用最后有效指针位置配合 hit-test，或平台真实 hover 事件；未知指针位置不猜成悬停，下一次真实输入再确定。触屏没有模拟 hover。
3. 恢复后指针确在触发器上则进入一致 hover，指针已离开则回到 idle 或其真实选中状态；键盘焦点提供定位反馈。既不能无条件恢复打开前 hover，也不能一律强制 idle；pointer 点击产生的 focus 不单独维持 hover。嵌套覆盖层未结束前不提前恢复背景可操作性。
4. 同一状态快照重定向所有组合轨道；按设计继续/退出光效，不留下孤立填充、半截遮罩、定住的高光或持续按压。动画中重新打开/关闭、resize、动态偏好变化也执行相同事务。

## 验收

对组合响应实测：边缘→中心 icon→文字→外部；hover→click→弹窗内移开→关闭；关闭时指针仍在源上；键盘打开/Escape 返回；触屏打开返回；半途反向、连续开关、取消和失焦。每条路径采样全部相关轨道在交接中及稳定后的状态，而非只查颜色或最终 aria。中心与边缘的命中、扫光位置/opacity、按压、焦点和业务状态均正确，恢复无需额外点击。
