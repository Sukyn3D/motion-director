# Motion Audit：覆盖、连续性和表现深度

先扫描真实用户路径和状态源，再按[coverage.md](coverage.md)检查范围内全部合格节点。源码发现候选，正常速度操作发现实际问题；三项分开记：覆盖缺口、连续性缺陷、表现单薄。

| 现象 | 决策 |
|---|---|
| 已有装饰带来品牌、美感或氛围，无明确冲突 | keep/enhance；非功能性不是remove理由，正常速度评审并保留价值 |
| 缩略图/来源点击后窗口直接出现 | add/enhance：记录真实源/目标，先核对实际封面，符合共享身份才连续图像交接，不同封面普通弹出；关闭检查布局/滚动稳定 |
| hover/focus使加号像关闭、播放/方向图形失真 | enhance：保留语义与方向，用局部缩放/颜色/填充/描边或对齐淡变替代，Icon不做独立位移/旋转 |
| 透明Icon/紧凑链接被统一加底色 | enhance：按表面与留白选择反馈；focus清楚但不强制填色 |
| 窗口返回时附属Icon/标签硬出现，媒体chrome闪现 | enhance：定义源/目标各层可见性、交接与全程chrome策略，逐阶段采样 |
| 某控件没有出现/hover/focus/press响应 | add：补齐相关矩阵，允许短、局部或父组覆盖 |
| 正常模式原有主反馈变弱 | 对比原基线，保留有效感知强度，修冲突或重设计，不以克制默认削弱 |
| 同一对象文案变化造成宽高跳动 | 接入实际外框尺寸与邻接布局，采样中间宽高与约束恢复 |
| 下滚文字/图片没有可见逐步入场 | 核对实际root/实例、透明度0→1与上移轨迹、阈值和reduce状态 |
| 不同卡片意图全部跟随鼠标 | 比较不同主机制，按内容/材质/选择/局部行动分族，不随机化同族 |
| 关闭弹窗主页抖动 | 检查滚动锁与补偿、来源占位、临时层、焦点滚动、背景重建/入场重播 |
| 一套换色或scale套遍所有控件 | enhance：按结构/动作分族，设计有因果的主次响应 |
| 快速改向从旧起点重新播放 | enhance：保留当前呈现及速度/身份，最新有效目标优先 |
| icon/色彩/展开状态硬切 | enhance：同一节点/对齐身份从当前值过渡，语义立即更新 |
| 只有首次scroll reveal，没有退出或重入 | enhance：建立可逆可见状态，反向无跳跃 |
| 柔软对象只播放固定晃动 | enhance：接触、速度/加速度驱动形变，释放交接并耗散 |
| 真实拖动被缓动追赶 | enhance：位置跟输入，材料层与释放才模拟 |
| 多主角抢注意、长stagger锁操作 | reduce：幅度、次轨道或组延迟；仍保持覆盖 |
| 非交互卡片被赋予可点击hover | remove误导轨道，内容组进退可保留 |
| 临时副本进入真实节点/动作查询 | 隔离class/ID/data-action，inert/aria-hidden，验证中途计数 |
| 完整且合适的原生/已有动效 | 评估进一步细化方向后keep，记录表现优势、保留理由、生命周期与家族覆盖证据 |

证据卡：节点/家族、功能/审美价值、实际删减证据与替代、矩阵覆盖、observed/inferred/unknown、连续性、复合表达、keep/enhance/add/reduce/remove/defer、优先级、方案、验收。优先级决定先后，不删除必需项。

报告分母：合格实例/家族数、全部矩阵已设计与已实现数量、已有满足项、例外、缺口、实际验证范围。10处8处已完整、2处改进可以成功；10处8处缺反馈只改2处不能称完成。完整覆盖是必要条件，美感不能按数量计分。
