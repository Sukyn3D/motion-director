# 弹出、详情与媒体窗口：来源到目的地

弹出动效已有Popover/Dialog/Sheet/卡片详情原料；本规则补齐实际来源与关闭关系。点击产生的新层或视图正常模式不能默认硬切，也不能只把全页从opacity=0变1当作来源交接。

## 先决定转场策略，再核对资格

普通窗口的完整非线性入退是默认方案。共享图像是可选表达：实际素材/对象一致、可见来源和正确几何仅是必要条件，还须符合对象关系、页面气质与用户偏好，具名记录采用理由。不能因为检测到同图就自动飞行；详情/人物/视频等家族都遵守同一策略判定。用户指定不飞行时，把该偏好作为该任务范围内的显式策略，覆盖打开、关闭、切换对象、快速反向和所有来源入口；不得靠个别选择器排除而漏掉某个变体。此用户选择不泛化为所有项目永久禁止共享元素。

## 按真实关系选择

| 场景 | 空间设计 |
|---|---|
| 可见缩略图→同一对象，且源/目标实际封面图像一致 | 可选择共享图像几何交接，保留主体与裁切关系；播放器/正文、蒙层独立显现 |
| 缩略图与弹窗封面不同，即使业务对象相同 | 使用普通窗口的非线性弹出/退场（如淡入与有界缩放或适合的边缘展开），直接呈现目标封面；不强行用缩略图一路放大再换图 |
| 触发器→菜单/Popover | 从真实锚点和合适transform-origin展开，边缘碰撞重算；不把小按钮放大伪装为同源图片 |
| 真实底边/侧边来源的Sheet/Drawer | 从对应边缘展开，内容与蒙层分轨，返回方向一致 |
| 无可见来源、深链、对象不同 | 明确短空间/淡变或实际边缘来源；不伪造shared identity、不制造不存在的父子关系 |

来源型弹出不是让每个窗口从按钮飞出。先记trigger、sourceID、实际几何与可见性、destinationID、状态/媒体身份；以真实关系说明来源。共享图像资格同时要求真实对象身份与实际视觉素材连续：核对资源/asset身份、currentSrc、poster/目标封面及版本，不只看相同业务ID或layoutId。不同图片、身份未知或加载后会换封面时选普通弹窗，先避免图像跳换；不能通过强行复制同一图伪造资格。普通弹窗同样有完整入退、蒙层/内容分轨与可打断性，不是硬切。普通窗口同样需要连续入退；选择共享方案且资格成立时不能随意退化为硬切；确实受平台/API/来源条件限制时具名记录替代。

## 同源缩略图到视频窗口

以下仅用于已核对实际封面一致的路径。普通弹窗独立呈现目标素材，不创建跨源飞行图；其焦点、媒体、关闭及布局恢复仍适用下文。媒体实际播放首帧可以不同，但首帧就绪的显现须有受控交接；这不能作为静态封面不同仍强制shared的理由。

1. 输入后窗口语义立即进入打开状态，按真实模态/非模态处理焦点与背景；关闭始终可用。来源图像/容器从当前矩形到目标矩形非线性运动，不阻塞业务请求或要求用户等预备动作。
2. 明确图片裁切、object-fit、主体焦点与目标比例；不能简单非均匀拉伸图像。若不同宽高比，使用保留内容比例的裁切/容器变化或受控局部交接。
3. 空间、圆角、蒙层、正文/控件与媒体显现分轨。将播放/关闭Icon、缩略图标签、海报/首帧、字幕/进度/媒体chrome都纳入源端、展开中、窗口态、收回中、归位后的可见性合同；按是否属于端点决定显示与隐藏，而非交接结束统一恢复。保留同源poster到真实首帧可用，不因播放器还没解码就闪黑，也不为假动画声称视频已加载/播放。
4. 媒体加载/播放/暂停/错误由实际状态决定。播放Promise失败有可操作提示；关闭按产品合同暂停/停止媒体，音频不能等退场结束才停；仅有海报的范例必须标明不是播放实现。
5. 中途关闭从当前呈现反向；关闭再打开使用最新目标，清理过期回调/临时层。不可为动画锁住关闭或把背景提前恢复成可点击的假模态。
6. 关闭前重测来源与目标；来源滚走、删除、尺寸变化或不是同一对象时不飞向旧坐标，用具名的短退出/当前窗口收敛。焦点返回仍在场的触发器，否则落到合理工作流节点。来源端专有Icon/标签要在归位前以对齐淡变或一致视觉层交接，保留至真实层已经接住，不能等dialog关闭才硬出现。媒体chrome策略全程一致，不因pause/hover或转场结束短暂暴露不属于设计的控制条；选择自定义控件时保留真实状态、键盘和可用操作，不一概删掉所有产品的进度/字幕。

布局与视口变化重算端点，从当前呈现接续；临时视觉副本inert/aria-hidden，无业务类/ID/data-action污染。真正窗口保持正确label、关闭入口、键盘/系统返回与媒体控制；不把非模态Sheet误当模态。

减少动效可短淡变或立即终态，保留来源标记、状态与可操作性，免除大幅空间飞行。无动画/API/no-JS路径仍能到达内容；原生系统管理的弹出可native-verified，缺失自定义部分补齐。

## 触发器状态与窗口内切换

源控件的 hover、focus-visible、press 与扫光/填充等组合轨道在打开与返回时按 [interaction-state.md](interaction-state.md) 同步校准；原生 close/focus 返回本身不证明源控件恢复正确。返回不需要额外点击空白处。

保持窗口打开而切换内部对象时，按 [layout-continuity.md](layout-continuity.md) 让 frame、媒体、正文、控件和邻接位置在同一布局事务中交接。不能只动画外框高度而立即替换里面的自然布局，也不能等外框结束再让图文跳变。不同媒体身份不伪造同对象 morph，可让旧/新内容按各自约束对齐交叉淡变；焦点、aria、滚动和最新业务内容立即正确。

## 关闭后主页布局稳定

弹窗状态不应重排主页。开启前记录scrollX/Y、背景代表锚点在文档与视口的位置、滚动容器可用宽度、相关body/root内联样式与滚动锁owner。悬浮窗口/临时层通过项目portal或独立覆盖层隔离，不进入主页普通flow；来源占位保留，不能为飞行把真实缩略图/卡片从布局删除。

沿项目现有模态滚动锁管理；检查滚动条消失/恢复造成的可用宽度变化，按实际平台用稳定滚动槽或测得的滚动条补偿，避免同时叠加两种补偿。关闭清理需幂等并保留嵌套窗口的锁计数，恢复原样式而非清空他人设置；移动端固定body方案还需正确还原偏移与scroll位置。

动画收回、临时层移除、来源可见性、背景解锁及焦点恢复按同一关闭生命周期交接，避免过期回调触发第二次布局。焦点归还默认不追加滚动（Web可用focus的preventScroll适配）；触发器不可见时依据实际工作流处理，不让隐藏旧触发器把主页滚到旧位置。窗口关闭不重建整页、不重新播放全部主页入场，也不把补偿当作新的响应式断点或布局动画。布局稳定不通过禁用正常主页滚动实现。

验收打开前、关闭中、解锁/临时层清理前后与恢复焦点后：在无用户滚动/内容变更的控制条件下，背景锚点与容器宽度保持同一布局，scroll位置不跳。用文档坐标区分真重排和真实滚动；测试有/无滚动条、窄屏、深滚动位置、连续开关及嵌套弹窗。记录合理的测量容差，不把明显抖动当弹性或用全页动画掩盖。

## 可观察验收

关闭完成包含真实蒙层透明端点；仅内容退出后调用 close 会瞬切原生 backdrop，属于失败。按 [lifecycle-regressions.md](lifecycle-regressions.md#2-蒙层是退出完成条件) 设置独立 effect owner、完成 barrier 与最新意图回调，采样 backdrop 自身。适用 Web 原料：`../assets/runtime/dialog-motion.mjs`。

实际点击/键盘触发，采样源→目的的中间矩形与图像裁切、蒙层/内容效果；检查真正媒体首帧与加载错误，不只查animation类。分别检查相同封面与不同封面分支、开到一半关、关后重开、Escape/返回、resize、来源滚走/删除、关闭后主页锚点/滚动/宽度、减少动效及焦点/媒体生命周期。数值可证明中间几何，不自动证明观感自然；正常速度评审来源是否清楚、图像是否失真；逐帧检查内部Icon、标签与海报交接，从最后一个临时层帧到第一个真实层帧没有硬闪，首尾和中途没有计划外chrome。

模态语义与键盘焦点参考[WAI-ARIA APG Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。该资料支持模态行为要求，不要求共享元素动效；上述运动与媒体合同为本包自主设计。
