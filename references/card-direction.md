# 卡片hover：按内容与语义选择主机制

卡片不是一种统一动作。先辨别作品/媒体探索、商品选择、摘要阅读、密集工具、状态编辑与品牌展示；记录用户已有喜欢的表现，再确定主响应对象。输入位置只是可选来源，不默认让整张卡片随鼠标移动。

| 结构 / 意图 | 可比较的主机制 | 相关次响应与边界 |
|---|---|---|
| 大图作品 / 摄影 | 裁切内图像缩放、遮罩显露、预览切换 | 标题/元数据保持可读，边缘/行动反馈呼应；预览按真实内容切换 |
| 有实体表面的品牌展示 | 光泽扫过、边缘光、接触阴影或适配的深度 | 光感说明材质；保持真实命中和文字，不同时强行叠全套 |
| 摘要 / 内容阅读 | 内部细节显露、局部展开、阅读关系与布局过渡 | 操作始终可发现；不让整个阅读面追逐光标 |
| 可选择商品 / 对比 | 选择框、填充、勾选与比较区的真实关系 | 选中与hover分离；真实数量立即更新 |
| 密集工具 / 编辑对象 | 原位边缘/线条/色彩、局部行动或状态层次 | 短而清楚，focus与hover区分；不统一磁吸抬升 |
| 少量有材料/空间意义的品牌物体 | 受控倾斜、材料响应或磁吸 | 只有其空间意图与品牌适合才选，触屏/键盘有替代；Icon局部不转不移 |

选型时比较适用的不同主机制，参考 [reference-libraries.md](reference-libraries.md) 的实际预览/源码；不同的跟随参数、颜色或弹簧力度仍属于同一机制，不算充分选型。所选关系按当前结构改造/组合并补齐生命周期。同一语义/结构家族应保持一致，不为了凑种类随机给每张卡片不同动画。

回查整页的家族分布：不同意图全落到同一种鼠标跟随，需要说明依据并重新比较相关的其他机制；满足场景与已有风格时同族重复是合理一致性。磁吸不是禁止项，也不设置固定种类配额；它的地位与其他机制相同，不能因为范例现成就成为卡片默认答案。

正常速度检查主反馈可感知、品牌协调、文字/布局稳定、hover leave和快速切换可靠。触屏以按压/真实状态补充，不复制依赖精确鼠标位置的体验；focus独立清楚。方案变丰富同时保留既有有效强度，参考案例的数量不代表项目表现已提升。
