# 内容驱动的尺寸与布局连续

适用于同一组件因文案、状态、加载结果、计数、校验消息、展开收起、图片/字体加载或断点变化而改变自然宽高和邻接位置。出现这类变化时，本项就是适用能力，必须接入实际控件，不能仅完成颜色或Icon过渡。

## 接线与端点

1. 列出全部真实内容状态及改变尺寸的触发，包括快速反向和异步更新。保持组件身份/稳定key；真实值、标签与aria立即改变，视觉可用对齐内容交接来接住变化。
2. 确认谁控制外框宽高与邻接布局：CSS布局、框架layout或测量控制器。测量当前呈现和新内容在实际父约束、字体、padding、border、gap下的自然端点；需要临时测量时隔离业务节点并保留约束。
3. 用平台layout、实际宽高或适配FLIP过渡到新端点；内层文字、Icon和图像保持比例与清晰度，内容显露/对齐淡变与外框协作。不能拉伸整个按钮的字形，也不永久预留最大宽度来掩盖本应伸缩的状态。
4. 普通 `width:auto` / `height:auto` 的transition不能作为已实现证据。按项目实际支持选择内在尺寸插值；不支持时测量两个端点再过渡。检查min/max、flex/grid伸缩、内联布局和写死的width是否让尺寸动画失效。外框是尺寸采样对象，不能只采样内部label/图标。
5. 从当前宽高与位置重定向；取消旧完成回调与过期异步目标。邻接项平滑让位，换行/行列拓扑变化使用真实layout机制处理；同一轴只有一个owner。
6. 结束解除临时固定尺寸，恢复自然布局，并比较解除前后几何：`auto`恢复造成跳一下仍失败。适配字体就绪、resize及后续内容变化；动态减少动效直接稳定到真实端点。

## 可观察验收

在实际组件上触发短→长→短，以及半途反向。记录外框旧/新宽高、至少一个介于端点之间的尺寸、文本比例、邻接项位置、最终状态与释放约束后布局。端点确有变化而只看到两种尺寸属于硬切，不算通过。检查窄屏、异步内容、快速多次输入和减少动效；端点本来相同的固定容器不伪造尺寸变化，相关内容/状态过渡仍须落实。

示例合同片段可并入现有JSON验收，用项目真实选择器替换：

~~~json
{"probes":[{"selector":"button[data-action='save']","axis":"w","motion":true}],"identity":["button[data-action='save']"]}
~~~

同时提供会改变自然宽度的真实短/长文案触发步骤与最终断言；上面只是探针片段，不能单独当完整测试。宽高动画的布局成本在目标环境检查，不以一律避免布局为由遗漏已要求的尺寸连续。

## 同一内容跨呈现方式：测量整个对象关系

提交须符合 [lifecycle-regressions.md](lifecycle-regressions.md#3-无闪帧的布局事务) 的可见原子性；首帧和全部可见 survivor 都要检查，outgoing 不用近似拼贴假冒当前呈现。新增层须通过同文档中“动效层几何透明”回归，不把媒体 auto/max 高度变成失效的 wrapper 继承链。

网格、列表、自由排布、折叠/展开等是同一业务对象的 presentation change，不是重新出生。稳定业务 key 与同一视觉内容身份连续；已有对象不得用新网格入场代替移动/缩放，只有新增对象获得 birth。appearance、scroll、hover 和 layout 分层，切换方式不重播原有对象入场，也不能继承前一对象的状态。

测量层、呈现层与坐标空间写入合同。getBoundingClientRect 是变换后的视口几何，不是可直接回写 CSS width/height 的自然布局尺寸；祖先 zoom/scale、旋转、滚动、border-box、object-fit、裁切和 transform-origin 都须参与转换。选择平台 layout 或 FLIP 时显式处理坐标空间、当前变换和约束，禁止把缩放后的 70% 视觉宽度当作 100% CSS 自然目标。旋转后的轴对齐 bbox 也不能当未旋转图像尺寸。

同一图像连续交接 position、width/height 或等价比例几何、orientation、clip/crop 和主体焦点；卡片外框连续不证明图像连续。列表缩略图→网格大图须同时移动与放大，自由排布→网格须协同归正与放大；文本和图标保持自身比例，必要时不同内容层交叉淡变，不随整卡 FLIP 拉伸。图片/封面、正文、卡片、容器及邻接重排形成同一事务，各属性只有一个 owner。

切换前采样当前呈现，应用目标布局并按目标父约束测自然端点，再以同一事务的逆变换/平台机制接住变化，避免新布局闪一帧。中途改向从当前呈现、合理速度和最新目标继续；resize、素材/字体加载重新测目标并重定向，不能把旧完成回调应用到新布局。解除临时 width/height/transform 前后实际几何一致，任何最后一下归位、比例跳变或一秒后“自行恢复”均为失败。

验收所有支持的视图有向切换（每一对的两个方向），包括半途切回、连续切换、悬停中切换、窄屏及祖先缩放/旋转。分别采样代表图像的矩形/比例/朝向/裁切、卡片及受影响邻接位置，核对中途与终点；实查全部实例目标尺寸和旧样式清理。不同结构/素材变体分别实测，不能只查容器最终 class。

## 文案重排与弹窗内外协同

先以真实目标约束测量新内容的自然排版，再让视觉内容按该排版与外框协作。短标签→长标签时，不把新长标签直接塞入尚未变宽的旧窄外框而让它临时换行；可用独立按端点排版的内层、受控显露或旧/新内容对齐交叉淡变。短单行标签可以局部保护换行，但不能全站 white-space:nowrap/固定最大宽度以破坏真正需要换行的响应式布局。保持完整标签可到达和语义立即正确；中途不能剪掉必要内容或将字形缩放拉伸。

外框宽高、内层图文和受影响邻接位置共享本次测量事务与时序目标，不要求所有属性共用同一缓动。内容替换可按各自最终宽度预排版，但视觉交接必须连贯；外框先变完、图片/文字随后跳一下不算协同。对于真实行列拓扑/文本换行变化，不声称能通用变形字行；采用适合的分层布局/淡变，让端点排版清楚且过渡没有错误中间布局。

验证长→短和短→长、各方向中途反向、窄屏合法多行、字体延迟、异步替换；弹窗 next/previous 跨不同图片比例和文本长度，采样 frame、图片、正文锚点和邻接项，检查整个过程而非仅高度曲线。临时约束释放使用仍属当前事务的目标，解除前后无顿挫；ResizeObserver 不直接强写另一 owner 的中间尺寸，不制造测量—写回反馈环。
