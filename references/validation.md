# 实现、运行、检查、修正

1.0先核对[coverage.md](coverage.md)的家族/变体/实例接线，再沿下文验收实际路径。完整覆盖、复合响应、滚动进退、材料及新增工具说明见[verification-1.0.md](verification-1.0.md)。scroll输入可指定selector/block或窗口top/left，count断言可检查中途业务节点数；新合同例为`assets/craft/checks.json`。

## 最小有意义验证

根据所选交互跑正常、一次打断/反向、最新意图的快速序列、减少动效，以及对应键盘/触控、取消/失焦/卸载。看初段、中途和结束的连续帧。最终 aria/数据对了，不能证明运动真的发生；类名/helper 出现了也不是证据。

检查：业务与语义立即更新；能继续操作；对象与节点身份连续；一个属性无多个所有者；实际目标、文字与点击区稳定；动画结束可读；动态减少动效保留功能。触屏应有按压/状态替代，不能靠 hover。自定义导航、dialog 等沿用其完整平台/无障碍语义，不为漂亮转场丢掉焦点。

案例库采用项共用上述验收，记录源组件与改造后实际实例的对应。重点检查默认一次播放、输入分支、全局清理、初始隐藏及依赖是否适配当前合同；按实际读到的代码选择相关项。外部预览、源码阅读、项目运行分别标明，未观看预览不能记为视觉通过。详见 [reference-libraries.md](reference-libraries.md)。

## 内容、布局与感知回归

控件/覆盖层/过滤/新呈现层的验收须包含 [lifecycle-regressions.md](lifecycle-regressions.md) 四条真实复现路径：click/drag→不点击空白而移出、backdrop透明后移除、首帧及全部survivor无闪跳、原版与增强版媒体/邻接几何一致。样例 `../assets/regressions/index.html` 便于验证通用机制；仍须应用到项目，不以样例通过代替项目检查。

按[execution-completeness.md](execution-completeness.md)回查适用能力；以下按真实任务选择，不新增独立原则打卡：

- 尺寸变化：触发实际短/长内容，采样外框w/h及邻接位置、中间值、反向和恢复自然布局前后；只有label淡变或最终宽度正确不能通过。
- 滚动：真实正常模式下滚/上滚，记录文字、图片/UI透明度和相对测量外层的呈现位移；视口中须有可观察渐入上移，不能只查装饰或最终opacity。
- 弹窗：分别判断同图/异图策略；在无用户滚动/业务重排条件下采样关闭前后背景文档与视口锚点、容器可用宽度、scroll位置及焦点，不把锁补偿或页面入场重播造成的抖动包装成动效。
- 感知：在同设备/偏好/输入下比较改前改后主反馈；记录有证据的保留或调整。轨迹有变化不等于人可感知，视觉/品牌评审与数值分开。
- 卡片：查看实际家族的主机制与选型，确认不同意图没有无理由套同一鼠标跟随，同族仍协调。

## 提供的 Web 验证器

`node scripts/verify-motion.mjs --url <本地URL> --spec <JSON合同> --output <报告.json>`。

依赖项目已有 Playwright；`--playwright-module <模块目录>` 可指定已存在的运行时。不自动下载包或浏览器。没有依赖/运行能力时退出并明确未执行，而非标通过。样例合同：`assets/lab/checks.json`。

合同每条测试独立打开页面，执行真实鼠标/键盘步骤，按 rAF 采样 bbox/transform/opacity，验证中间变化、节点身份、最终属性及相关语义。通常用自己的 selectors 和动作替换样例。测试脚本只读 DOM 与执行输入，不重写曲线、库或业务。

`motion: true` 要有可观察中间变化；`motion: false` 用于减少动效的自主运动检查。直接手势本身允许移动，别把真实跟手当减少动效失败。颜色短淡变也可合规，合同应只禁止相关非必要空间运动。不能仅靠 sampled 字符串数量评价美感。

合同字段：`setup` 建立输入前状态；`steps` 执行触发；`immediate` 查即时语义；`probes` 指定选择器、CSS `property` 或几何 `axis`（x/y/w/h）、是否有中间 `motion`、点击区是否 `stable`；`identity` 检查 DOM 对象；`after` 释放输入/后续操作；`final` 检查稳定结果。支持 click、focus、hover、key、keydown/keyup、down/up、move、drag、wait、reduce。选择器应唯一；多元素用各自明确选择器，尤其 `.entry` 采样只代表匹配的第一个元素。

坐标使用文档空间，避免把自动滚动误报为点击区移动；切换系统减少动效偏好后等待媒体查询提交再采样。`stable` 用于点击区/直接拖动后的保持，不适用于本来就应移动的视觉图层。项目有初次加载动画时，按实际节奏设置 `initialWait`，避免把无关动画当目标的变化。验证器不会证明曲线正确性或每个状态都覆盖。

只对本地范例或授权的测试环境执行。真实业务写入、付款、发送等流程使用测试数据/模拟，不用动效验证擅自触发；默认脚本只接受 file/localhost 地址。

## 性能与证据边界

优先正常速度体验，再用同步对照/局部放大/轨迹解释。记录浏览器、viewport、偏好、输入顺序与实际执行结果。若量性能，必须同设备、同负载、同路径，并使用真实 profiling；headless rAF 间隔、布局 API 耗时或少量采样不能宣称真机60fps。

失败先定位状态重启、动画属性竞争、过期回调、ResizeObserver 强设终点、节点重建、取消缺失等原因。只修证据支持的问题，复测受影响路径。通过后不再循环测试或扩大修改范围。

结构检查：官方 `quick_validate.py` 只检查 skill 包结构，不证明决策质量。运行 `scripts/test-spring.mjs` 验证解析物理，不证明整页体验。审美/克制需要正常速度观察与用户/盲评判断；无法运行、触屏模拟与真实设备验证应分别说明。

## 30套展厅回归

`scripts/verify-gallery.cjs` 为展厅的可便携行为验证器，需现有 Playwright及已安装Chromium，不自动安装。使用环境变量 `PLAYWRIGHT_MODULE` 指定已存在的模块路径（省略则标准require解析），`MOTION_GALLERY_URL` 指向展厅本地HTTP地址（默认 `http://127.0.0.1:8765/assets/gallery/index.html`），`MOTION_REPORT`和`MOTION_SCREENSHOT`指定输出位置。CLI首参数可为逗号分隔ID，进行针对性复测并合并旧报告；首次完整运行不传ID。

覆盖30套各自的正常中间呈现、减少动效、模拟触控、稳定目标及反馈，另查部分快速反向、共享对象身份与卸载。少量快速流程只检查最新意图与身份，不声称测出速度连续性。展厅内部共享运行时可复用，但产品仍需自己的状态与实际路径验收。完整回归仅在修改模式/运行时时需要，不强制每次调用运行整个展厅。

`scripts/verify-accessibility.cjs`使用相同现有Playwright依赖与本地URL配置，补测导航键盘、Escape恢复焦点、动画中动态减少动效、移动端溢出、异步竞态和卸载。报告默认`accessibility-validation.json`（可用`MOTION_REPORT`覆写），只支持本地展厅。它是行为回归，不构成完整无障碍认证。

## 状态、造型与布局的专项验收

按实际适用路径选择以下探针，保留正常速度录制/观察与中间几何、样式证据；不以通过总数替代未覆盖的路径。

| 风险 | 真实输入与观察对象 | 失败条件 |
|---|---|---|
| 图片与叠加内容 | hover 峰值/退出、press，长标签/窄屏；检查图片层及文字/按钮的实际裁切祖先 | 必要文字/图形被裁、标签跟随 mask 消失 |
| 造型反馈 | 圆形、透明 icon、range 各自 hover/press/cancel 与键盘 focus-visible | 通配矩形 press 框；滑块仅拖动才有反馈；去掉键盘定位 |
| 全范围命中 | 控件边缘、中心 icon、文字、内边距，观察真实命中/事件与响应 | 中心死区、子元素切换误触 leave、视觉层截获输入 |
| 覆盖层往返 | 指针打开→移到窗口内/源外→关闭；指针仍在源上关闭；键盘 Escape；触屏返回；半途开关 | 旧 hover/pressed 残留；底色与扫光不同步；额外空白点击才恢复 |
| 普通/共享策略 | 全部独立入口及返回，含同图人物、视频、详情/深链；查策略及临时视觉层 | 同图自动越过普通/禁飞策略；某个入口仍有图像飞行 |
| 同组一致性 | 同结构各实例 enter/leave 的层、幅度归一和核心关系，实测独立变体 | 由素材格式偶然决定机制；同组漏 hover |
| 双向滚动 | 同对象四个边缘进退，窗口及嵌套 root，正常速度可见帧与反向 | 只证明一次入场；退出完全离屏才发生 |
| 跨呈现方式 | 所有视图有向切换/半途切回；图像 position、size、rotation、crop 与邻接；旧约束解除前后 | 以 birth 替代同图移动缩放；旧比例残留再跳正；错误布局稍后自愈 |
| 内容/响应式 | 标签长短双向与中途反向；窄屏合法换行、字体加载；弹窗 next/prev 不同比例与文本长度 | 新文字临时挤进旧宽度换行；frame 先完再跳图文；auto 解除顿挫 |

纯数值或 DOM 绑定证明不了裁切可读性、扫光协调与反馈造型。发现异常先查实际属性 owner、坐标空间、状态模型与测量事务，修复原因；不能靠延迟、动画锁、强制最大尺寸、全局 nowrap、关闭后模拟空白点击、移除所有 focus outline 或统一减弱表现掩盖问题。验证器未测这项就如实记录未知；一次通过不保证所有设备无缺陷。
