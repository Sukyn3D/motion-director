# 1.0：覆盖、复合响应、进退和材料的验证

先核对coverage矩阵：全部合格家族/变体已设计、实例确实接线；原生反馈需native-verified证据。核对覆盖不意味着全部实例重复跑同一测试；不同状态、变体、平台不能未经检查共用结论。

## 可复用工具

- `node scripts/verify-craft.cjs`：四组范例的正常中间呈现、非恒速空间运动、状态反向、稳定目标、滚动退出/重入、focus保护、真实拖动形变/惯性、动态减少动效、卸载及no-JS。故意放入一个硬切样本校准检查器。现有Playwright，由PLAYWRIGHT_MODULE指定；MOTION_CRAFT_URL为授权本地HTTP；MOTION_REPORT为报告位置，不安装依赖。
- `node scripts/verify-motion.mjs --url <localURL> --spec <JSON> --output <report>`：产品合同验证器，现有依赖使用`--playwright-module`。1.0例：`assets/craft/checks.json`。新增scroll输入（selector/block或窗口top/left）与count断言，可检查中途业务节点数；完整字段和限制见[validation.md](validation.md)。
- `node scripts/test-spring.mjs`：30/60/120Hz、重定向、过冲、稳定、长dt和参数非法值。证明标量求解器特性，不证明产品每帧表现或真机性能。

## 各维度怎样实测

先核查[并列设计依据](design-foundations.md)合同：五个视角均有适配决定及对应证据，不将任何来源只作背景。所有轨道分类且owner明确，空间/效果参数不混用，适用的主次、材质、节奏等机制有家族决定与证据，共用评审，不增来源专属必填流程。设计评估与量测分开；正常速度视觉评审检查主次、编排和表现，数值断言不能自动判定审美优秀。

| 维度 | 输入与证据 |
|---|---|
| 非线性 | 正常输入后记录实际位置/尺寸，查看初段、中途、末段变化率；从静止出发有加速和稳定减速，非恒速位移 |
| 复合响应 | 对实际表面与子元素分别采样，检查方向/主次与取消；属性多不等于设计优秀 |
| 并列依据共同评审 | Apple交接、Material分轨、Disney主次、Fluent层级编排与Carbon语义效率都有关联证据，不能只验证某一体系跳过其余视角 |
| Material分轨 | 同一次真实输入分别采样空间轨迹与颜色/alpha；空间轻弹性有界，效果不随其过冲且范围合法；快速反向保留当前呈现，检查实际子图形而非仅父层 |
| Disney适配 | 对照家族中适用的表演/材质/节奏决定；形变/跟随/节奏等所用原则有对应呈现证据，预备不延迟操作、主次不争抢、形体不破坏可读性，决定与其他视角共用记录 |
| 状态/颜色/icon | 实际点击后aria立即、呈现经过中间值，同一节点/身份；检查实际填充/路径/内部icon而非只查父控件。若更换形状，证明受控的交接层/交叉淡变；父节点不换不能证明内部图形没有硬切。过渡中再点，从当前值接续，最后是最新状态 |
| 空间连续 | 中途反向/改目标，测实际框/矩阵C0；按合同测x/v与可见速度C1，固定tween不自动保证C1 |
| 滚动 | 下滚、上滚、退场中反转、数次重入、focus/held保护、无JS、初始及动态减少动效；只测一次fade-in不足 |
| 材料 | 慢拖与快速晃动有不同且有界形变；接触位置跟手，快速释放继承速度，停住再释放不伪造惯性；重抓/取消/边界稳定 |
| 暂态隔离 | 副本在中途也是inert/aria-hidden且不混入真实class/ID/data-action/业务查询；只看结束数量会漏故障 |
| 全生命周期 | 失焦、pointercancel、卸载、偏好动态切换后不残留运动/失效目标；pagehide的persisted暂停与真正卸载分开，pageshow恢复不丢控制器；App后台/前台按平台生命周期验证；颜色opacity合法、真值准确 |

至少一次真实输入经过产品事件路径。量测先用正确样本校准，再用已知具体故障确认会失败；故障注入只允许隔离测试范例，不用于真实业务。阈值来源标为设计合同/自定起点/平台/测量，headless采样不等于真机FPS。

行为、覆盖、运动连续与审美分开交付。家族清单完整不是“所有设备无缺陷”证明；未执行的输入、App编译、辅助技术、真机profiling均标未测。修复证据支持的问题，复测受影响路径；通过后不为堆证据反复跑全库。

## 项目实际呈现

正常速度保留审美价值，检验细化方向；完整下滚上滚采样真实标题、正文和UI，检查实际滚动root、可见带与聚焦目标；弹出及返回逐阶段记录图像、Icon、标签、正文、蒙层和媒体chrome，确保交接结束不闪回附属元素。透明/紧凑实例按空间反馈，Icon局部无独立平移/旋转，形状与状态准确。不能只检查helper、类名、外框或最终opacity。

[交互体验范例](../assets/experience/index.html)与`scripts/verify-experience.cjs`是机制样本，需已有Playwright和本地HTTP；不代表真实产品已经验收。
